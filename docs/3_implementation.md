# РОЗДІЛ 3. ПРОГРАМНА РЕАЛІЗАЦІЯ, РОЗГОРТАННЯ ТА ЕКСПЕРИМЕНТАЛЬНА ВЕРИФІКАЦІЯ СИСТЕМИ

> *Статус документа: Шаблон розділу (заповнюється в межах Етапів 4–6 календарного плану).*

## 3.1. Програмна реалізація серверного ядра, асинхронних воркерів та інтеграційних шлюзів

- Структура проєкту та реалізація асинхронного REST API шлюзу на базі `FastAPI` (Python 3.12) і `SQLAlchemy 2.0 (AsyncIO)`.
- Реалізація фонових воркерів `ARQ`: багатоканальна інгестія (`yt-dlp`, `trafilatura`), модуль локальної транскрибації аудіопотоків (`faster-whisper`) та багатомовний NLP-конвеєр (`spaCy` із лінивим завантаженням моделей `en`, `de`, `es`).
- Реалізація двоконтурної інтеграції зі штучним інтелектом (`Jev` та `LLM API` зі *Structured Outputs*), механізмів контролю лімітів (Rate Limiting) і резервного перемикання провайдерів (Graceful Degradation).

## 3.2. Реалізація підсистеми інтерактивного тріажу, адаптерів експорту (`.apkg`, `.tsv`, `.csv`, `.md`) та контейнеризації

- Реалізація підсистеми інтерактивного тріажу та зваженої стейт-машини життєвого циклу знань користувача (`NEW` $\rightarrow$ `LEARNING` $\rightarrow$ `KNOWN` або `IGNORED`).
- Програмна реалізація шару файлових адаптерів експорту та імпорту: генерація бінарних архівів Anki (`.apkg` через `genanki`), а також текстових пакетів для Quizlet (`.tsv`), Brainscape (`.csv`), RemNote та Obsidian (`.md`).
- Конфігурація контейнеризованого середовища розгортання за допомогою `Docker` та `Docker Compose` (сервіси `api`, `worker-default`, `worker-transcribe`, `postgres`, `redis`, `minio`).

## 3.3. Інструментальний аудит якості коду, модульне та навантажувальне тестування

- Результати інструментального аудиту якості та статичної типізації вихідного коду (`Ruff`, `Mypy`).
- Покриття кодової бази модульними й інтеграційними автотестами (`Pytest`, `Pytest-Asyncio`).
- Методика та результати навантажувального стрес-тестування пропускної здатності асинхронних черг (`Grafana k6`) та експериментальна верифікація коефіцієнта локального відсікання слововживань на CPU (`spaCy + SQL + Jev`).
