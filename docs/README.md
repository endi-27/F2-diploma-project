| Код | Категорія | Ключове технічне обмеження (2026) | Метод верифікації |
| :--- | :--- | :--- | :--- |
| `NFR-01` | Продуктивність API | `p95 <= 200 мс` на синхронних точках доступу при `100–150 RPS` | `Grafana k6` |
| `NFR-02` | Диспетчеризація черг | Постановка в `Redis 7 / ARQ` за `p99 <= 25 мс` (`HTTP 202 Accepted`) | `pytest-asyncio` |
| `NFR-03` | Дедуплікація в БД | Індексний пошук за гешем `SHA-256` у `PostgreSQL 16` за `<= 15 мс` | `EXPLAIN ANALYZE` |
| `NFR-04` | Локальна транскрибація | Безперервне аудіо до `120 хв` через `faster-whisper (INT8)` без `25 MB` фрагментації (`RTF <= 0.85` на `CPU`) | Бенчмарк `worker`-контейнера |
| `NFR-05` | Автентифікація і доступ | `JWT Bearer` (сумісний з `OAuth 2.0`), `RBAC`, TTL `<= 30 хв`, `Argon2id` | Модульні тести (`Pytest`) |
| `NFR-06` | Захист і `Rate Limiting` | `HTTPS / TLS 1.2+`, `Pydantic v2`, лімітер `Token Bucket` у `Redis 7` | `Ruff`, `Mypy`, API-тести |
| `NFR-07` | Комплаєнс `GDPR` | Каскадне видалення даних користувача `<= 5.0 с`; `Zero Data Retention` для `LLM API`; автовидалення в `MinIO` | Інтеграційні тести БД / `HTTPX` |
| `NFR-08` | Відмовостійкість | До `3` повторних спроб з `Exponential Backoff with Jitter`; `Graceful Degradation` до `System-1` за `<= 500 мс` | Chaos / mock-тести (`Pytest`) |
| `NFR-09` | Інфраструктура | `spaCy <= 450 МБ RAM`, `faster-whisper <= 2.0 ГБ RAM`, старт `docker compose up -d` за `<= 120 с` | `Docker stats`, `CI/CD` |
